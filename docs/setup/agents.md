# agents

Встроенные режимы Kilo (файлов агентов в `.kilo/agent/` и `~/.config/kilo/agent/` не нашёл — определены в самом Kilo):

- **code** — режим по умолчанию: читает, правит файлы и запускает команды в рамках прав из `kilo.jsonc`.
- **ask** — только чтение: ищет и анализирует, но файлы не трогает и мутирующие команды не вызывает.
- **plan** — планирование: сначала строит план изменений (шаги/файлы), и только после одобрения переходит к правкам.
- **debug** — диагностика: фокус на поиске причин сбоев (логи, стектрейсы, воспроизведение), минимум правок до локализации бага.
